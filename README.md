# Shopping Cart System with Remaining Stock

## Description
This project is a console-based shopping cart system written in C#. It allows users to select products, input quantities, and manage a cart while tracking remaining stock.

## Features
- Product menu display
- Input validation
- Stock checking
- Cart system with no duplicates
- Receipt generation
- Discount for purchases above 5000
- Updated stock after checkout
